# Implementation status and verification

This document records the initial implementation honestly. Local simulator evidence cannot establish compatibility with production Kafka, MSK, external identity providers, or a live Kubernetes cluster. The design documents describe desired behavior; this table is the release evidence boundary.

| Area | Implementation/evidence | Release gaps |

## Packaging checks performed

- Embedded SQLite support: the final full backend race suite against local Kafka/PostgreSQL plus SQLite tests passed 174 tests with zero test skips or failures; `go vet ./...` passed on rerun. An initial concurrent verification attempt hit a Go standard-library import-cache error. Docker built successfully with the pure-Go SQLite driver. A read-only, non-root real-mode container with a writable named data volume authenticated, listed sessions and read local Kafka topics without a PostgreSQL connection. After container restart the original authenticated session remained valid. A second container sharing the SQLite volume was rejected by the process lock. Temporary fixture credentials, containers and the test volume were removed. SQLite tests cover restart persistence, throttle ownership, cancellation/fencing, one-use OIDC state, future schema rejection and audit rollback. Both Compose files validate; Helm lint/render passed and rejects SQLite HPA/multiple replicas. Real Kubernetes deployment and SQLite backup/restore drills remain unverified. See [storage](storage.md).

- Session administration: latest full backend race suite against local Kafka/PostgreSQL passed 149 tests, zero test skips or failures; `go vet ./...` passed. Inventory uses opaque SHA-256 handles, bounded pagination and global `manage-sessions` permission. Revocation requires CSRF, confirmation and target-user authorization; PostgreSQL audit/deletion commits atomically. Real PostgreSQL tests verify audit-write failure rollback and second-pool session invalidation. Eleven focused frontend component tests and four Chromium workflows passed, including custom roles, failure/retry, self-revocation, demo behavior and 390px layout. Browser responses are intercepted protocol fixtures. Native frontend production build passed. Full user/role CRUD remains unimplemented.

- Latest session-policy backend race suite with local Kafka/PostgreSQL passed 144 tests, zero test skips and zero failures; `go vet ./...` passed. ## Exploratory scale measurements

On an AMD Ryzen 9 9950X3D, the command `cd backend && go test ./internal/balance ./internal/simulator -bench . -benchtime=3x` passed. Three synthetic iterations averaged 52.46 ms per 5,000-partition plan. JSON metadata serialization averaged 8.65 ms for 15 brokers / 6,000 topics / 30,000 partitions and 27.18 ms for 100 brokers / 10,000 topics / 100,000 partitions. These are in-process synthetic measurements; production concurrency, network, memory and browser load budgets remain unverified.
